# Mode_Switching-Flight_control-Pid_Controller-
Verilog-2001 based copter flight-control PID hardware featuring cascaded attitude and rate loops for roll, pitch, and yaw. Supports Acro, Stabilize, Altitude Hold, and Failsafe modes with anti-windup, bumpless transfer, derivative filtering, watchdog protection, RTL verification, Cadence Genus synthesis, and Innovus physical-design analysis.
